# Aplicación Web de Finanzas Personales

<p>
Aplicación web para la gestión y análisis de finanzas personales, desarrollada con Java y Spring Boot.

El objetivo del proyecto es permitir a los usuarios registrar, organizar y analizar sus movimientos financieros, controlar presupuestos, gestionar objetivos de ahorro y administrar sus deudas.
</p>
